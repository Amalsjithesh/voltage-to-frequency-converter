# Voltage to Frequency Converter

![Hardware Implementation](v%20to%20f%20image.png)

## 📌 Project Overview

A Voltage-to-Frequency Converter is a circuit that converts an
input voltage into a corresponding output frequency.

This project was designed and implemented using an LM741
operational amplifier and Passive components 

## 🔧 Components Used

- LM741 Op-Amp
- Resistors
- Capacitors
- Zener Diode
- 9V Batteries

## ⚡ Output

- Target Output Frequency: 10 kHz
- Supply Voltage: ±9V
